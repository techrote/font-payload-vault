# abandonware

Fonts you soured on after actually using them. Not deleted, just retired: a parts bin of glyphs, metrics and ideas
that didn't survive daily life.

Move a font here whole (fonts, source, docs) and add a line below saying why it soured, so future-you doesn't make the same font twice.
