# Gasket Sans

Proportional, angular sans for UI labels and short command-line prose. Bevelled
joins replace curves: every round form is an octagonal polyline.

- Style: Regular, 1000 units/em, 254 encoded characters, true lowercase
- Files: `fonts/GasketSans-Regular.ttf`, `fonts/GasketSans-Regular.woff2`
- Source: `source/design.py` (centre-line paths; rebuild with `python tools/fourth_cohort/cohort.py`)
- Proofs: `specimen/specimen.svg`, `specimen/character-map.svg`, `specimen/index.html` (offline tester)
- Licence: SIL Open Font License 1.1, see `OFL.txt`

See [DESIGN.md](DESIGN.md) for intent, construction and limits.
