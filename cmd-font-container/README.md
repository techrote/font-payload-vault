# cmd-font-container

Terminal, command-line and "system UI" fonts: things that belong in a console, a taskbar, a start menu or a DOS box.

| font | what it is |
|---|---|
| [`knurled-swarf/`](knurled-swarf/) | **Knurled Swarf**: hand-tuned multi-size pixel font, sharp at every size from 6 to 16px, Regular + VGA-style Bold. TTF, per-size TTF, Windows .fon, WOFF2, BDF + full build source. |
| [`latchline-mono/`](latchline-mono/) | **Latchline Mono**: original scalable monoline instrument face; fixed-pitch text, genuine lowercase, explicit character distinctions. Regular TTF + WOFF2, source, proofs and design notes. |
| [`collet-sans/`](collet-sans/) | **Collet Sans**: proportional oval-and-stem UI face; open forms, true lowercase, tabular digits. Regular TTF + WOFF2, editable master, proofs and design notes. |
| [`detent-slab/`](detent-slab/) | **Detent Slab**: angular fixed-pitch alphabet with selected slab terminals and dotted zero. Regular TTF + WOFF2, editable master, proofs and design notes. |

Each font gets its own folder with its fonts, a README, a specimen, and the complete source/workflow needed to rebuild it.
