# cachemonic

Cursed, glitched and deranged experiments: corrupted-on-purpose faces, broken grids, generative weirdness, fonts that probably
shouldn't exist. If using it daily should get you onto a watchlist, it lives here.

**Name lineage:** **Cachemonic** (cache + demonic), #1 on the second-pass leaderboard in
[the name ratings](../docs/subfolder-name-ideadump-refonly.md): watchlist **11**, chuck-wrap 10, cybernetic 8.
A demonic cache is the right home for things you can't stop poking at.

| font | what it is |
|---|---|
| [`cache-rattle/`](cache-rattle/) | **Cache Rattle**: original seven-column pixel master with deterministic row tearing. Fixed-pitch display experiment, not a daily-use terminal face. Regular TTF + WOFF2, source, proofs and design notes. |
