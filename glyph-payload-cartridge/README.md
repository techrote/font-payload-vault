# glyph-payload-cartridge

Icon, symbol and dingbat fonts: glyph sets delivered into UIs, HUDs, status bars and tray menus rather than read as text.

**Name lineage:** from [the name ratings](../docs/subfolder-name-ideadump-refonly.md):
**Payload** (#2 overall, total 46, cybernetic 10, watchlist 10) + **Cartridge** (cool 8, cybernetic 7: a swappable
module you slot in) + Haiku's **Glyphload**. One cartridge, many payloads.
