# Ratchet Block

Heavy display capitals for short headlines, poster labels and workshop signage.

- Style: Regular, 1000 units/em, 254 encoded characters, monospaced 600-unit cell
- Lowercase input is set as reduced small capitals, not text lowercase
- Files: `fonts/RatchetBlock-Regular.ttf`, `fonts/RatchetBlock-Regular.woff2`
- Source: `source/design.py` (heavy 120-unit bevelled strokes)
- Proofs: `specimen/specimen.svg`, `specimen/character-map.svg`, `specimen/index.html`
- Licence: SIL Open Font License 1.1, see `OFL.txt`

See [DESIGN.md](DESIGN.md) for intent, construction and limits.
