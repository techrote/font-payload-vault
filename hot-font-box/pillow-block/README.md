# Pillow Block

Very heavy rectilinear letters with softened convex corners, for posters.

- Style: Regular, 1000 units/em, 254 encoded characters, true lowercase
- Files: `fonts/PillowBlock-Regular.ttf`, `fonts/PillowBlock-Regular.woff2`
- Source: `source/design.py` on the shared `BLOCK` skeleton (`tools/sixth_cohort/lineages.py`)
- Proofs: `specimen/specimen.svg`, `specimen/character-map.svg`, `specimen/index.html`
- Licence: SIL Open Font License 1.1, see `OFL.txt`
- Rebuild: `python tools/sixth_cohort/cohort.py`

See [DESIGN.md](DESIGN.md).
