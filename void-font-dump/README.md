# void-font-dump

Experiments, abandoned attempts, broken builds and retired versions: anything that isn't (or is no longer) a real font.
Dump here instead of deleting; a dead end today is a parts bin tomorrow.

**Name lineage:** the two top abandonware scorers in [the name ratings](../docs/subfolder-name-ideadump-refonly.md):
**Dump** (#1 overall, total 47, abandonware **11**) + **VoidFont** (#7 overall, abandonware **11**).
It is the only folder in this repo whose job is to be abandoned, and its rating says it will do that job extremely well.

Suggested layout: `void-font-dump/<font-name>/<yyyy-mm-dd>-<what-went-wrong>/`
